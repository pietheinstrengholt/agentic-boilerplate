# Wine Journal glossary

The current demo uses these terms:

- **Account**: A named demo user who can sign in. Account passwords are stored as salted verifiers, not plaintext.
- **Session**: The browser's signed sign-in state. It ends when the person signs out or the cookie expires.
- **Wine Journal**: The demo application. Its current welcome screen previews future wine features without linking to unfinished pages.

The next iteration may introduce these product terms. They are not current models or API resources:

- **Wine**: A named wine associated with a Region.
- **Region**: The geographical origin shown for a Wine.
- **Tasting**: An occasion on which someone samples a Wine.
- **Tasting note**: The observations recorded for a Tasting.

Refine these definitions when the product rules become concrete.
